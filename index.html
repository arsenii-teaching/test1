Workshop guide

TN-AI Day 3

Third meeting

Build your first small site

Follow the steps below to set up VS Code, ask Cline to create a starter project, and test it in your browser.

01

Install VS Code

Download and install Visual Studio Code.

02

Install Cline

Install the Cline extension. It is easier to set up than Continue for this session.

03

Connect your account

Register with your school email, agree to the terms, and choose the free GLM-5.3-Flash model.

04

Create and open a folder

Create a new folder in your preferred work directory, then open it in VS Code.

05

Write your prompt

Create a file called prompts.md and add the starter site request below.

# My Site Project
- Create a placeholder site using html+css+javascripts.
- Don't use fancy graphics [will be changed later].
- Input greeting for me. My name is Input Name.
- Create a button that gives random greeting.
06

Ask Cline to execute prompts.md

Give Cline the file and let it generate the starter project.

07

Install Live Server

Install the Live Server extension to preview your project quickly.

08

Preview your site

Right-click the generated index.html and choose Open with Live Server. Then make it more creative.
