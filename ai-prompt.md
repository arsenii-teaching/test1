# Project: My Small Interactive Site

## Tech Stack
- HTML5, CSS3, JavaScript (vanilla)
- No external libraries (to keep it lightweight)
- Deployment: GitHub Pages

## Design Goals
- Make a minimalistic blackjack casino.
- Say hello to Terry.
- Light, modern colour palette (#2c3e50, #ecf0f1, #3498db).

## AI Prompts

### 1. Generate HTML structure
> Prompt: "Create a semantic HTML5 layout for a landing page with a header (logo + nav), hero section (title + subtitle + CTA button), about section (image + text), and a contact form with name, email, and message fields."

### 2. Generate CSS
> Prompt: "Write mobile‑first CSS for the above layout. Use a consistent colour scheme. Include a navigation bar that becomes a hamburger menu on small screens (pure CSS)."

### 3. Generate JavaScript
> Prompt: "Add smooth scrolling for internal anchor links. Validate the contact form (required fields and email format) and show a success alert on submit."

### 4. Testing plan
> - Open `index.html` in a browser.
> - Test responsiveness using dev tools.
> - Verify form validation.
